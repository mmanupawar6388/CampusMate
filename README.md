# CampusMate

CampusMate is a local student AI assistant built with a fine-tuned GPT-2 model, Python utilities, and Gradio.

## Features

- Chat
- Study Mode
- Viva Practice
- Calculator
- Percentage calculation

## Model

The trained GPT-2 model is hosted on Hugging Face:

https://huggingface.co/manupawar6388/campusmate-gpt2

## Local Run

```bash
pip install -r requirements.txt
python app.py
